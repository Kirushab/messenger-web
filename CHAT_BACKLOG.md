## 🟢 Высокий приоритет — польза × автономность

### 1. Форматирование текста (markdown)
*Жирный* / _курсив_ / `моноширинный` / ~~зачёркнутый~~ и авто-ссылки в тексте сообщений. Сейчас текст рендерится как plain (только превью ссылок и jumbo-эмодзи работают).
**Объём:** M · **Риск:** низкий (парсер + рендер в пузыре; можно без панели тулбара, только синтаксис).

### 2. Поиск внутри чата
Иконка поиска в шапке → искать по сообщениям открытого диалога, подсветка совпадений, прыжок «вверх/вниз» по результатам. Метод `searchMessages` в сторе **уже есть**, не хватает UI и навигации по результатам.
**Объём:** M · **Риск:** низкий (переиспользует flashMessage для прыжка).

### 3. «Прочитано кем» в группах
Сейчас только булева галочка «кто-то прочитал». Добавить список конкретных участников, кто прочитал (тап по сообщению → «Прочитали: …»). Данные `memberReadTimes` уже есть.
**Объём:** S–M · **Риск:** низкий.

### 4. Индикатор «изменено»
Помечать отредактированные сообщения меткой «изм.» / «edited». Поле `edited_at` есть в данных, но в UI не показывается.
**Объём:** S · **Риск:** низкий.

## 🟡 Средний приоритет

### 5. Удаление «для себя» / «для всех»
Сейчас удаление одно (общее). Дать выбор: удалить только у себя (скрыть локально) vs удалить у всех. Стандарт мессенджеров.
**Объём:** M · **Риск:** средний (нужна доп. логика/поле скрытия на стороне БД).

### 6. Очистить историю чата
Кнопка «Очистить переписку» в меню/инфо чата.
**Объём:** S–M · **Риск:** средний (массовое удаление — аккуратно с подтверждением и RLS).

### 7. Стикеры / GIF
Наборы стикеров и/или поиск GIF (Giphy/Tenor). Сейчас есть только крупные эмодзи. Это интеграция со сторонним API + пикер + отправка как медиа.
**Объём:** L · **Риск:** низкий по коду, но внешняя зависимость (ключ API, лимиты).

### 8. Внешний шеринг / ссылка на сообщение
Системный Share сообщения и/или «копировать ссылку на сообщение» (deep-link на конкретное сообщение). Сейчас шарятся только события.
**Объём:** M · **Риск:** низкий (нужен роутинг по `?msg=` + прокрутка к нему).

### 9. Множественный закреп (карусель)
Сейчас закреп один (`pinned_message_id`). Поддержать несколько закреплённых с переключением в панели сверху.
**Объём:** M · **Риск:** средний (меняется модель закрепа — одно поле → список).

### 10. Реакции: полный список «кто что поставил»
Сейчас показываются аватары первых + счётчик. Добавить шторку с полным списком по каждой реакции.
**Объём:** S–M · **Риск:** низкий.

## ⚠️ Отложенные риск-задачи (трогают ядро ленты — делать осторожно, после обкатки скролл-фич)

### #17. Sticky-даты
Дата «прилипает» сверху и держится до следующего дня. Требует перегруппировки ленты по дням в секции (сейчас дата лежит внутри обёртки одного сообщения, чистый `position:sticky` так не сработает).
**Объём:** M · **Риск:** ВЫСОКИЙ (меняет структуру `map` ленты → может задеть скролл/divider/группировку/refs).

### #21. Пагинация вверх (ленивая подгрузка)
Грузить последние N сообщений + подгружать старые при скролле вверх, со сохранением позиции. Сейчас грузятся первые 100 (`order ascending limit 100`) — на больших чатах неоптимально.
**Объём:** L · **Риск:** ВЫСОКИЙ (переделка `fetchMessages` + новый `loadOlder` + сохранение scrollHeight при prepend; пересекается с divider, кнопкой «вниз», realtime).

## Рекомендованный порядок

1. **Быстрые победы:** #4 (изменено) → #3 (прочитано кем) → #10 (список реакций) — мелкие, низкий риск, заметны.
2. **Главная пара:** #1 (форматирование) + #2 (поиск в чате) — максимум пользы, автономны.
3. **Среднее:** #5/#6 (удаление для себя / очистка), #8 (ссылка на сообщение), #9 (мульти-закреп).
4. **Крупное по желанию:** #7 (стикеры/GIF) — самая «вау», но внешний API.
5. **Риск-задачи в конце:** #17 и #21 — только после того, как текущие скролл-фичи (divider, кнопка-вниз, группировка) обкатаны на реальных данных.

_Нишевое (#11–#19) — по необходимости, не блокирует ощущение «чат готов»._
