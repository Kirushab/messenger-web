# v391 changelog

## Исправлено

- Убраны системные дубли уведомлений в уже открытом активном чате.
- Убрано одновременное фоновое local notification + Web Push.
- Клик по уведомлению открывает конкретный чат даже при уже запущенной SPA.
- При выходе push endpoint больше не остаётся привязанным к предыдущему аккаунту.

## Добавлено

- Web Push для сообщений, файлов, альбомов, пересылки и offline-очереди.
- Web Push для прямых/групповых звонков и приглашений.
- Серверные настройки direct/group/calls/previews.
- Учёт mute, блокировок, @упоминаний и ответов.
- Удаление протухших подписок после HTTP 404/410 от push-сервиса.
