# v391 — настройка фоновых Push-уведомлений

## Что уже находится в архиве

- `supabase/migrations/172_push_notifications.sql` — таблицы, RLS и RPC для подписок.
- `supabase/functions/send-push/index.ts` — доставка сообщений и звонков.
- `public/sw.js` — показ push и переход в нужный чат.
- `src/lib/pushNotifications.ts` — регистрация браузера и синхронизация настроек.

## 1. Применить миграцию

В Supabase Dashboard откройте **SQL Editor**, вставьте содержимое
`supabase/migrations/172_push_notifications.sql` и выполните запрос.

## 2. Создать VAPID-ключи

На локальном компьютере:

```bash
npx web-push generate-vapid-keys
```

Сохраните пару ключей. Public key используется и клиентом, и Edge Function;
private key — только сервером.

## 3. Добавить переменную клиентской сборки

В окружение Vite/Render/Cloudflare Pages добавьте:

```env
VITE_WEB_PUSH_PUBLIC_KEY=<Public Key>
```

После изменения переменной обязательно пересоберите и разверните frontend.

## 4. Добавить secrets Edge Function

```bash
supabase secrets set \
  WEB_PUSH_PUBLIC_KEY="<Public Key>" \
  WEB_PUSH_PRIVATE_KEY="<Private Key>" \
  WEB_PUSH_SUBJECT="mailto:<ваша-почта>"
```

`SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` доступны Edge Functions проекта.

## 5. Развернуть функцию

```bash
supabase functions deploy send-push
```

В `supabase/config.toml` для неё включено `verify_jwt = true`. Функция дополнительно
проверяет пользователя и не принимает готовый список произвольных получателей:
получатели вычисляются по составу чата на сервере.

## 6. Проверка

1. Откройте приложение по HTTPS или как установленную PWA.
2. Войдите в аккаунт → **Настройки → Уведомления и звуки**.
3. Включите **Push-уведомления** и разрешите их в системном диалоге.
4. Отправьте сообщение с другого аккаунта, когда приложение закрыто или в фоне.
5. Проверьте прямое сообщение, группу, @упоминание, ответ, файл и входящий звонок.
6. При открытом целевом чате системный push не должен появляться; сообщение остаётся в UI и воспроизводит локальный звук согласно настройке.

## Ограничение iPhone/iPad

Для фонового Web Push на iOS приложение должно быть добавлено на экран «Домой» и
запущено как PWA. Разрешение запрашивается только после нажатия пользователя на
переключатель в настройках.

## Откат

Frontend продолжит работать без ключа, но экран настроек покажет, что push-сервер
не настроен. Для полного удаления серверной части удалите функцию `send-push` и
таблицы `push_subscriptions`, `notification_preferences` после резервного копирования.
